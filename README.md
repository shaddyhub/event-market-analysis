# 🎯 MICE & Corporate Events Market Analysis

> Market sizing, city benchmarking, and satisfaction drivers in the B2B corporate events industry.

## 📌 Project Overview
An industry-specific analysis of the Meetings, Incentives, Conferences & Exhibitions (MICE) market — examining destination value, event type profitability, and client satisfaction trends.

## 🔍 Key Questions Answered
- Which cities deliver the highest event value?
- What event formats generate the most revenue?
- How has the market grown year-on-year?
- What drives client satisfaction scores?

## 📊 Key Insights
- Dubai and Singapore command the highest price-per-person-per-day
- Conferences dominate volume; Incentive Trips drive highest margins
- Events with <8 weeks lead time correlate with lower satisfaction
- Year-on-year market recovery is visible across all cities

## 🚀 How to Run
1. Clone or download this repository
2. Open `notebooks/mice_market_analysis.ipynb` in Jupyter
3. Run all cells in order
